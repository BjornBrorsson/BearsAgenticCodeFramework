## 5-Layer Teaching Method

1. **Why & Mental Model:** Explain the real problem it solves and the 3–5 core concepts in plain language before showing code.
2. **Visual Flow:** Draw a clean Mermaid diagram (`Trigger/UI → Route/Handler → Service → DB/API`).
3. **Guided Code Tour:** Walk through the 3–5 key functions/files in execution order with **Durable Deep Links** (`symbolName()` in `src/...` (`~L42`). `_Verified: YYYY-MM-DD._`), explaining *why* they are written that way.
4. **Gotchas & Traps:** Highlight the common mistakes (and link to `./docs/MASTER_MEMORIES.md`).
5. **Try It Yourself & Persist:** Give a quick command or query to see it live, offer 2–3 next drill-down steps, and save new feature docs to `./docs/wiki/<feature>.md`.
