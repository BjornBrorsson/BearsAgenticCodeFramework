## Lesson Template
1. **Why & Mental Model:** 2–3 sentences on the problem solved + key terms.
2. **Mermaid Flow:** `UI / Trigger → Route / Handler → Service → DB / API`.
3. **Guided Code Walkthrough:** 3–5 key functions in order with **Durable Deep Links** (`symbolName()` in `src/...` (`~L42`). `_Verified: YYYY-MM-DD._`).
4. **Common Gotchas:** Top traps from `./docs/MASTER_MEMORIES.md`.
5. **Try It Live:** A quick command or read-only query + 2–3 next drill-down options.
